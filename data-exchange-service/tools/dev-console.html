Exchange Service — Dev Console

1. Health

Confirms the service, Postgres, and MinIO are all reachable.

2. Data products & entitlements

Lists active data products this identity's tenant can see.

3. Upload lifecycle (inbound)

Runs the full flow: initiate → signed PUT to MinIO → complete → fetch detail/events/validation.

4. My exchanges

Tenant-scoped list for the current identity.

5. Outbound publication (internal, simulated Gold)

Protected by an internal API key, not the tenant JWT — simulates a future Gold hand-off.

6. Multi-tenant isolation check

Fetches an exchange ID (from step 3 or 5) as the other tenant. A correct setup returns 404, not the data.
